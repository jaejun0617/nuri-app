NURI ADMIN CONSOLE

운영자 알림 발송 관리

이 페이지는 앱 내부 일반 사용자 화면이 아닌 별도 관리 페이지 트랙입니다. 단일 QA 대상 발송, 미리보기, audit 확인, home quick dismiss와 inbox delete 분리 smoke를 위한 최소 운영 콘솔만 제공합니다.

안전 가드

전체 발송과 push 발송은 이번 범위에서 비활성화됩니다.

  • admin/super_admin 세션만 운영자 발송 RPC를 호출합니다.
  • 대상은 QA fixture 닉네임만 선택하며 raw user id를 표시하지 않습니다.
  • service role key, FCM secret, push token은 입력하거나 표시하지 않습니다.

1. 콘솔 연결

운영자 계정으로 로그인합니다. publishable key만 사용하며 service role key는 사용하지 않습니다.

로그인이 필요합니다.

전체 발송

전체 사용자 broadcast는 후속 승인, opt-out, push 정책, 운영 리뷰가 완료되기 전까지 잠겨 있습니다.

QA self smoke

adminQA 계열 로그인 세션은 자기 자신에게만 `QA_RETENTION_` 알림을 만들 수 있습니다. 운영자 발송 권한이 없어도 live retention smoke를 반복할 때 사용합니다.

일일 5건 제한이며, 다른 사용자나 공지 원본에는 영향이 없습니다.

2. 단일 QA 대상 발송

운영자 알림은 단일 QA 대상에게만 보냅니다. 발송 후 audit log와 앱 알림함에서 확인합니다.

발송 전 미리보기를 확인하세요.

3. 미리보기

adminQA notice
QA_RETENTION_ADMIN_CONSOLE
운영자 알림 콘솔에서 생성한 home quick dismiss / inbox delete live smoke용 알림입니다.

4. Audit log

최근 발송 이력을 제한 필드만으로 확인합니다.

아직 불러온 audit이 없습니다. 운영자 로그인 후 새로고침하세요.
