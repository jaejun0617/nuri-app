# 프로젝트 전체 진행현황 통합 완성본

> 역할 안내(2026-11-10): 이 본문 전체의 작성일·판단 기준일은 **미확인**이다. 기존 로컬의 10/29 정정 날짜나 Git 저장 시점을 본문 전체의 기준일로 대신하지 않는다. 아래 86~89%, 85~89%, 55~60% 등은 과거 추정치이며 현재 수락 분모·후보와의 연결이 확인되지 않았다. 현재 개발률로 사용하거나 오늘의 통합 수락과 합산하지 않는다.

## 1. 문서 목적

이 문서는 과거 프로젝트 진행 추정과 도메인별 계획을 보존하는 지원 문서다. 최신 진행률의 기준 문서가 아니다.

현재 요약은 [현재 상태](../../project-memory/현재-프로젝트-상태.md), 실제 수락은 [단일 원장](../../qa/nuri-integrated-closeout-2026-10-25.md), 실행 순서·승인은 [우선순위](../../project-memory/다음-작업-우선순위.md)를 따른다. 아래 ‘현재’·‘다음’·‘최우선’은 당시 평가 문맥이다. 도메인 요구사항의 현재 적용성은 이번에 재판정하지 않았으며 서버·실기기·웹 운영도 재검증하지 않았다.

당시 문서가 제시한 목표는 아래 세 가지다.

- 앱과 웹의 현재 위치를 분리해서 본다.
- 도메인별 완료 범위와 남은 마감 작업을 한 번에 파악한다.
- 이후 작업 우선순위를 흔들리지 않게 유지한다.

## 2. 현재 전체 진행률

아래 원래 추정치는 산정 분모와 오늘의 검증 연결이 확인되지 않았다. 원문 이력으로만 보존한다.

- 전체 프로젝트: `86~89%`
- 앱 `nuri`: `85~89%`
- 웹 `nuri-web`: `55~60%`

판단 기준:

- 앱은 핵심 사용자 기능과 주요 도메인 구조가 대부분 열려 있고, 지금은 운영 완성도와 출시 마감 단계에 가깝다.
- 웹은 챕터 1~3 기반 구조는 열렸지만, 현재 우선순위는 앱 완성 쪽이므로 당분간 보류한다.

## 3. 앱 기준 진행현황

### 3.1 전체 앱 진행률

- 앱 전체: `85~89%`

### 3.2 핵심 도메인별 상태

- 인증 / 프로필 / 기본 홈 흐름: 완료에 가까움
- 멀티펫 / 펫 등록 / 펫 수정: 완료에 가까움
- 타임라인 / memory_images 구조: 핵심 범위 완료
- 집사 꿀팁 가이드: `93~96%`
- 출시 전 QA / 운영 마감: 진행 중

## 4. 집사 꿀팁 가이드 상태

### 4.1 챕터 기준 상태

- 챕터 1 완료
- 챕터 2-1 완료
- 챕터 2-2 완료
- 챕터 3-1 완료
- 챕터 3-2 완료
- 챕터 3-3 완료

즉, 집사 꿀팁 가이드는 새 기능 챕터보다 `운영 전환 / 최종 QA / 출시 마감 단계`에 들어와 있다.

### 4.2 현재 완료된 핵심 범위

- 홈 추천 / 더보기 목록 / 상세 / 검색
- 최근 검색어 / 인기 검색어
- seed fallback 정책
- 선택 펫 종 + 공통 팁 기준 목록 노출
- 세부 종 / 나이 / memorial 분기
- 추천 가중치 / 계절성 / 반복 노출 완화
- 이벤트 적재 / 리포트 SQL 점검 기준
- 관리자 브릿지 최소 CMS
- QA 체크리스트 / 운영 전환 체크리스트

### 4.3 남은 마감 작업

- 운영 공개 row 기준 최종 검증
- 실기기 최종 QA 실제 수행
- 추천 문구와 체감 튜닝 마지막 보정
- 필요 시 운영 리포트 화면 초안

## 5. 타임라인 메모리 이미지 시스템 상태

현재 상태:

- 구조 전환 핵심 범위 완료
- `memory_images` 전환 완료
- worker / backfill / fallback / preload 최적화 기준 정리 완료
- 운영 관찰 포인트 문서화 완료

남은 작업:

- 실제 운영 관찰 결과 기반 소규모 보정
- 출시 전 QA와 성능 점검 마감

## 6. 웹 CMS 상태

### 6.1 현재 진행률

- `nuri-web`: `55~60%`

### 6.2 현재 상태

- 챕터 1 완료
  - 공개 메인 / 로그인 / 관리자 읽기 구조
- 챕터 2 완료
  - 등록 / 수정 / 상태 변경
- 챕터 3 완료
  - 이미지 업로드 / 미리보기 / 관리자 UI 정리

### 6.3 현재 판단

- 웹 CMS는 구조적으로 시작은 잘 열렸다.
- 다만 현재 전체 프로젝트 우선순위는 앱 완성이다.
- 따라서 웹은 당분간 기능 확장보다 보류/유지 상태로 본다.

## 7. 산책 위치 기반 기능 상태

현재 상태:

- 우리동네 산책은 `현재 GPS 기반 주변 추천 + 직접 검색` 구조로 단순화 완료
- 거리 기준은 `현재 위치 기준`으로 단일화 완료
- 상세 / 연관 장소 더보기 / 외부 지도 열기 흐름 유지
- 검색 입력 화면 키보드 / 스크롤 안정성 1차 보강 완료

남은 확장 포인트:

- 현재 위치가 없는 상태에서의 검색 결과 UX 세부 보정
- 운영 검수 POI 데이터셋 연결 여부 검토
- 최근 검색어 / 즐겨찾기 / 길찾기 연동 검토
- 산책 기록 저장 여부 검토

- `docs/domains/산책-위치기반-기능/산책-위치기반-기능-구현-상세.md`

## 8. 지금 남은 최우선 작업

현재 우선순위는 아래 순서가 맞다.

1. 앱 운영 공개 row 기준 최종 검증
2. 앱 실기기 최종 QA
3. 집사 꿀팁 가이드 마지막 운영 마감
4. 타임라인/기록 도메인 출시 전 QA
5. 전체 프로젝트 문서/운영 기준 최종 정리

## 9. 99% 기준 남은 작업

프로젝트를 `99%`에 가깝게 보려면 아래가 필요하다.

- 앱 기준 공개 데이터와 seed fallback 전환 검증 완료
- 홈/검색/상세/프로필 수정 실기기 QA 완료
- 산책 위치 기반 기능 실기기 QA 완료
- 운영/테스트 데이터 혼동 없는 최종 정책 확정
- 주요 도메인 빈 상태/에러 상태/문구 마감
- 출시 직전 체크리스트 기준 패스

## 11. 결론

현재 프로젝트는 기능을 새로 여는 단계보다, `실제 운영과 출시를 위해 마감 품질을 올리는 단계`에 들어와 있다.

특히 앱 기준으로는:

- 큰 구조는 거의 열렸고
- 남은 것은 운영 전환, QA, 문구/체감 보정, 출시 마감이다.

즉 지금부터의 작업은 `무엇을 더 만들지`보다 `무엇을 더 안전하게 마감할지`가 중심이다.
