# V1.1 알림 dismiss 롤백 노트

기준일: 2026-07-02

## 범위

`20260702030000_v11_notification_dismissals.sql`은 앱 내부 알림 목록에서 사용자별 삭제 UX를 제공하기 위한 additive migration이다.

- `user_notifications.dismissed_at` 컬럼 추가
- `user_notification_dismissals` 테이블 추가
- `get_user_notification_unread_count_v1`, `get_user_notifications_v1`에서 dismissed 알림 제외
- `dismiss_user_notification_v1`, `dismiss_all_user_notifications_v1` RPC 추가

## 운영 의미

앱의 "삭제"는 알림 evidence를 물리 삭제하지 않고 사용자 본인의 read path에서만 숨기는 dismiss 처리다.

- 개인 알림: 본인 row의 `dismissed_at` 기록
- 공지 알림: `user_notification_dismissals`에 사용자별 숨김 기록
- 다른 사용자 알림/공지 원본에는 영향 없음

## 롤백 절차

실제 롤백이 필요할 때만 maintenance window에서 수행한다.

```sql
begin;

revoke all on function public.dismiss_all_user_notifications_v1()
  from public, anon, authenticated, service_role;
revoke all on function public.dismiss_user_notification_v1(uuid, text)
  from public, anon, authenticated, service_role;

drop function if exists public.dismiss_all_user_notifications_v1();
drop function if exists public.dismiss_user_notification_v1(uuid, text);

drop table if exists public.user_notification_dismissals;

alter table public.user_notifications
  drop column if exists dismissed_at;

-- 이후 get_user_notification_unread_count_v1, get_user_notifications_v1는
-- 직전 migration(20260701090000_v11_second_mvp_activity_notifications_xp.sql)
-- 기준 정의로 재배포한다.

commit;
```

## 주의

롤백 시 사용자가 삭제한 알림이 다시 목록에 보일 수 있다. 기능 자체가 release blocker를 만들 때만 수행한다.
