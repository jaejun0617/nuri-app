# V1.1 Walk POI National Expansion Roadmap

업데이트: 2026-06-15

## 결론

전국 산책/location discovery POI 확장은 외부 지도 API를 사용자 앱 runtime에서 호출하지 않는 방향으로 진행한다. 사용자 앱은 Supabase 자체 POI RPC만 호출하고, 외부 API는 필요 시 운영자 seed 보조 도구에서만 제한적으로 사용한다.

## Rollback 원칙

- 운영 데이터 delete를 기본 rollback으로 사용하지 않는다.
- 문제가 있는 row는 `held`와 `hidden`으로 public projection에서 제외한다.
- source/review/audit provenance는 유지한다.
- 개인정보성 raw payload나 라이선스 문제가 있는 데이터만 별도 승인 후 delete를 검토한다.
