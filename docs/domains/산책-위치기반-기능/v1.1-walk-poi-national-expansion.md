# V1.1 Walk POI National Expansion Roadmap

업데이트: 2026-06-06

## 결론

전국 산책/location discovery POI 확장은 외부 지도 API를 사용자 앱 runtime에서 호출하지 않는 방향으로 진행한다. 사용자 앱은 Supabase 자체 POI RPC만 호출하고, 외부 API는 필요 시 운영자 seed 보조 도구에서만 제한적으로 사용한다.

## 현재 기준선

- 앱 read path: `walk_poi_public_nearby_v1`, `walk_poi_public_search_v1`, `walk_poi_public_detail_v1` 우선
- fallback: Kakao Local 서버 경유 `location-discovery-seed` 유지
- coverage region:
  - 일산/주엽/호수공원 생활권, 기준 좌표 `37.676492,126.767888`, 반경 5km approved/public/active 37건
  - 백석/마두/정발산 생활권, 기준 좌표 `37.6433,126.7882`, 반경 5km approved/public/active 32건
- 총 approved/public/active POI: 53건
- fallback gate: coverage region 안에서 POI RPC 정상 응답 + 0건이면 Kakao fallback 제한
- 유지 fallback: `poi_disabled`, `coordinate_missing`, `poi_rpc_error`, `detail_not_found`, coverage region 밖
- Kakao Local runtime 삭제 여부: 이번 단계에서는 삭제하지 않음

## 전국 Seed 데이터 후보

- 공원: 근린공원, 문화공원, 생태공원, 어린이공원, 수변공원
- 산책로: 공원 산책로, 하천변 산책로, 수변 데크길
- 둘레길: 지자체 둘레길, 산책 코스, 숲길
- 수변 산책로: 호수, 하천, 강변, 해안 산책로
- 반려견 놀이터: 지자체 운영 반려견 놀이터와 반려동물 동반 야외 지점
- 반려동물 동반 가능성이 높은 야외 지점: 운영자 검수 전에는 candidate로만 취급

## Source / Attribution 기준

- 공공데이터: 지자체 공원/녹지/산책로 공개 데이터
- OSM: park, trail, path, leisure, amenity 기반 후보. attribution과 라이선스 확인 필요
- 운영자 승인 seed: NURI 운영자가 직접 검수한 지점
- 지자체 공개 데이터: 고양시, 서울시, 수도권 지자체 공개 목록 우선
- Kakao Local admin 보조: 사용자 runtime이 아니라 운영자 seed 후보 보조에만 제한

## 지역별 Batch 확장 순서

1. 고양시 1차 확장: 완료. 일산/백석권 gate 적용, 화정/행신/삼송/원당 보류.
2. 서울 주요 산책 권역 확장
3. 수도권 주요 공원/산책로 확장
4. 광역시별 확장
5. 전국 공공데이터/OSM batch 확장
6. coverage 충족 지역부터 Kakao fallback 축소
7. 최종적으로 Kakao Local 사용자 runtime 제거

## Rollback 원칙

- 운영 데이터 delete를 기본 rollback으로 사용하지 않는다.
- 문제가 있는 row는 `held`와 `hidden`으로 public projection에서 제외한다.
- source/review/audit provenance는 유지한다.
- 개인정보성 raw payload나 라이선스 문제가 있는 데이터만 별도 승인 후 delete를 검토한다.
