# V1.1 Walk POI Admin Import / Review Workflow

업데이트: 2026-06-06

## 목적

V1.1 산책/location discovery 자체 POI 전환에서 운영자가 seed 후보를 안전하게 반영하고, public projection으로 승격하기 전 검수/audit 경계를 유지하기 위한 admin workflow 기준 문서다.

이번 단계는 대량 import가 아니라 admin import commit/review 서버 계약을 만드는 작업이다. 앱 read path는 이미 자체 POI public RPC 우선 + Kakao fallback 병행 구조이며, 이번 workflow는 seed coverage 확대 전 운영 방어선을 먼저 세운다.

## Migration Index

이미 remote에 적용된 Supabase migration은 rename하지 않는다. Supabase migration history는 timestamp filename과 remote 적용 이력에 의존하므로, 직관성이 부족한 이름은 문서 index로 보완한다.

- `20260604110000_walk_poi_postgis_foundation.sql`: PostGIS foundation, canonical/source/import/review/audit/alias table, public RPC, admin dry-run RPC.
- `20260605090000_walk_poi_admin_import_review_workflow.sql`: admin import commit/review RPC, pending review 상태, audit log workflow.
- `20260605093000_walk_poi_admin_review_alias_conflict_fix.sql`: 이미 적용된 admin workflow migration을 rename/수정하지 않고, review RPC alias conflict ambiguity를 보정한 additive corrective migration.
- `20260606170000_walk_poi_admin_audit_detail.sql`: admin write UI e2e 증적을 위해 safe audit drill-down RPC를 추가한 additive migration.

새 migration naming convention:

- timestamp prefix 유지
- 영문 snake_case 사용
- 기능이 드러나는 이름 사용
- 한글 설명은 migration 상단 SQL comment 또는 문서에 기록
- remote 적용 완료 migration rename 금지

## Admin Import Commit RPC

RPC:

- `walk_poi_admin_import_commit_v1(p_source_provider text, p_payload jsonb, p_note text default null)`

권한:

- `admin` 또는 `super_admin`만 호출 가능
- 비관리자 `authenticated`와 `anon`은 `WALK_POI_ADMIN_REQUIRED` 또는 execute permission deny로 차단
- `SECURITY DEFINER`
- `search_path = public, extensions`

Payload contract:

```json
{
  "externalSourceId": "operator-seed:goyang:park:001",
  "name": "문화공원 오거리공원",
  "category": "park",
  "categoryLabel": "공원",
  "description": "운영자 승인 산책 POI 후보",
  "address": "경기도 고양시 일산서구 중앙로 1601",
  "roadAddress": "경기도 고양시 일산서구 중앙로 1601",
  "latitude": 37.676492,
  "longitude": 126.767888,
  "aliases": ["문화공원", "오거리공원"],
  "attribution": "NURI operator seed",
  "confidenceScore": 90,
  "qualityScore": 80,
  "raw": {
    "source": "operator-approved-seed"
  }
}
```

Commit 결과:

- `walk_poi_import_batches` commit batch 생성
- `walk_pois` hidden/pending canonical candidate 생성
- `walk_poi_source_records` pending source record 생성
- `walk_poi_reviews` pending review row 생성
- `walk_poi_search_aliases` alias 생성
- `walk_poi_audit_logs` `import_committed` 기록
- duplicate/conflict/skipped/create/review count 반환

Conflict 기준:

- `source_provider + externalSourceId`는 duplicate로 처리
- normalized name + address
- normalized name + coordinate proximity
- alias overlap은 후속 review에서 conflict 판단 근거로 유지

원칙:

- destructive overwrite 금지
- raw payload는 source record 내부에만 보관하고 public RPC로 반환하지 않음
- commit은 public 노출이 아니라 검수 후보 적재 단계

## Admin Review RPC

RPC:

- `walk_poi_admin_review_v1(p_walk_poi_id uuid, p_action text, p_reason text default null, p_patch jsonb default '{}'::jsonb)`

권한:

- `admin` 또는 `super_admin`만 호출 가능
- 비관리자는 `WALK_POI_ADMIN_REQUIRED`
- `SECURITY DEFINER`
- `search_path = public, extensions`

지원 action:

- `approve`
- `reject`
- `held`

Action 결과:

- `approve`: `walk_pois.review_status='approved'`, `visibility_status='public'`, `lifecycle_status='active'`, source record `linked`
- `reject`: `review_status='rejected'`, `visibility_status='hidden'`, source record `rejected`
- `held`: `review_status='held'`, `visibility_status='hidden'`, source record `held`

Audit:

- 모든 action은 `walk_poi_reviews`와 `walk_poi_audit_logs`에 reviewer, reason, diff를 남긴다.
- reject/held는 reason 필수다.
- approve도 reason을 권장한다.

## Public Projection Safety

앱 public RPC는 아래 조건의 row만 반환해야 한다.

- `review_status = 'approved'`
- `visibility_status = 'public'`
- `lifecycle_status = 'active'`
- 유효한 좌표

반환 금지:

- pending/rejected/held 후보
- source raw payload
- review internal diff
- audit log
- import batch 내부 상태
- 운영자 note

확인된 negative 조건:

- `anon` direct table SELECT 차단
- 비관리자 admin import commit/review 차단
- pending/rejected/held row는 public RPC 미노출
- approved/public/active row만 public RPC 노출

## Coverage / Fallback 축소 Gate

이번 단계에서는 Kakao Local fallback을 줄이지 않는다. seed coverage 확대와 public projection 안정성이 확인된 뒤 아래 기준을 gate로 사용한다.

Fallback 유지 조건:

- 지역별 approved POI coverage가 낮음
- public RPC error rate가 release 기준을 초과
- 검색 hit-rate가 낮아 empty UX 비율이 높음
- import/review rollback이 반복 발생
- 운영자가 seed provenance를 설명할 수 없음

Fallback 축소 후보 기준:

- 우선 지역 단위 approved/public/active POI coverage가 충분함
- 위치 기반 nearby empty 비율이 안정적으로 낮음
- 검색어 hit-rate가 기존 fallback 대비 사용자 경험을 훼손하지 않음
- public RPC latency와 error rate가 안정적임
- rejected/held/pending 누수가 0건으로 유지됨
- rollback SQL 또는 held 처리 기준이 준비됨

초기 관측 지표:

- 지역별 approved POI count
- nearby request 대비 POI result hit-rate
- search query 대비 POI result hit-rate
- fallback 호출 비율
- public RPC error rate
- import commit duplicate/conflict/skipped count
- review approve/reject/held 비율

Rollback 기준:

- public projection 누수
- admin gate 우회
- 앱 산책 리스트/상세 crash
- fallback 경로 장애
- 운영 seed provenance 불명확

## 2026-06-06 Admin Write UI E2E / Audit Detail

일곱 번째 단계에서는 최소 admin write UI를 실제 admin/super_admin 세션에서 직접 조작하고, action log drill-down까지 확인했다.

추가 RPC:

- `walk_poi_admin_audit_detail_v1`

반환 범위:

- audit log id
- action type
- target POI name/category/status
- reviewer id
- reason/note
- created_at
- before/after state snapshot

반환 금지:

- source raw payload
- provider token
- secret
- import raw body
- 사용자 계정 전체 이메일

UI 결과:

- 화면: `산책 POI 운영`
- approve button tap e2e: 성공. action 후 review queue가 refresh되고 상태가 `approved/public/active`로 반영됨.
- reject button tap e2e: 성공. empty reason validation 확인 후 `reject-e2e-0606` reason으로 반려됨.
- held button tap e2e: 성공. empty reason validation 확인 후 `held-e2e-0606` reason으로 보류됨.
- action log drill-down: 최근 `review_approve` audit log를 탭해 action, target, reviewer, reviewed_at, reason, before/after state를 확인함.
- 일반 사용자: QA admin role 복구 후 전체메뉴에서 운영 섹션 미노출 확인.

운영 데이터 정리:

- admin UI e2e용 QA 후보는 action 확인 뒤 public projection에서 제외되도록 `held/hidden` 상태로 정리했다.
- 실제 운영 row delete는 수행하지 않고 review/audit provenance를 유지했다.

Security result:

- `walk_poi_admin_audit_detail_v1`는 admin/super_admin만 호출 가능하다.
- 비관리자는 `WALK_POI_ADMIN_REQUIRED`로 거부된다.
- public projection은 approved/public/active row만 반환한다.
