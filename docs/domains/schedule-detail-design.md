## 기능

- 반려동물 이름을 일정의 문맥으로 표시한다. route의 petId와 서버 일정의 petId가 다르면 상세를 열지 않는다.
- 완료 토글은 `completed_at`만 변경한다. 서버 응답을 다음 화면 상태와 알림 재예약 기준으로 사용해 기존 기록 연결·메모·알림·외부 동기화 필드를 덮어쓰지 않는다.
- 완료 후 상세에 머문다. 완료 표시만으로 기록을 자동 생성하지 않는다. 사용자가 기록으로 남기기를 누를 때 기존 기록 작성 화면을 연다.
- 제목·메모·분류·KST 날짜를 작성 화면에 채운다. 미래 일정의 조기 완료는 기존 DB 계약을 보존하되 실제 기록 날짜를 미래로 만들지 않고 현재 날짜를 초기값으로 사용한다. 건강·급여량 등 필수 항목을 임의 값으로 채우지 않는다.
- 일정에서 시작한 작성 임시 저장은 사용자·반려동물·일정별로 분리한다. 일반 작성 임시 저장을 읽거나 지우지 않는다. 계정이 바뀌면 기존 내용을 새 계정에 저장하지 않는다.
- 저장한 기록 ID를 별도 복구 키에 보존한다. 일정 연결 실패 후 재시도는 기존 ID만 연결한다. 동시에 두 번 누르는 제출도 잠근다. 기존 사진 업로드·활동 후처리 경로는 유지한다.
- 복구 저장소 실패가 기록 저장 실패로 오인되지 않게 안내한다. 이 경우 서버 기록은 타임라인에 남지만 앱 종료 후 자동 연결 복구를 보장하지 않는다.
- 기록 연결은 로그인 사용자와 반려동물이 일치하는 기록·완료된 일정을 조건으로 처리한다. 이미 다른 기록이 연결됐으면 덮어쓰지 않는다. 같은 ID의 재시도는 허용한다.
- 연결된 기록 보기·수정·삭제 후 복귀는 일정 상세 문맥을 유지한다. 기존 연결 FK의 기록 삭제 시 SET NULL 계약을 재사용한다.
- 알림 안내는 현재 기기의 앱 알림·시스템 권한·채널·정확한 시간 권한에 근거한다. 권한이 정상이어도 해당 일정 예약 또는 실제 도착을 보증한다고 표시하지 않는다.
