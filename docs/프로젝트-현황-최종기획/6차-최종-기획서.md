# 6차 최종 기획서

작성일: 2026-05-06

## 1. 문서 목적

이 문서는 NURI 6차 기획서 세트의 최상위 index이자 최신 source of truth다. v1.0 기능 기준선과 v1.1 업데이트 방향을 분리해, 지금 닫힌 범위와 다음에 확장할 범위를 명확히 고정한다.

## 2. 6차 기획서가 최신 기준선인 이유

- v1.0 기능 개발은 Code Freeze 상태로 고정됐다.
- v1.0은 스토어 제출 완료 버전이 아니라 기능 개발 기준선이다.
- v1.1은 v1.0 미완성 이월이 아니라 신규 업데이트 트랙이지만, v1.0 잔여 task와 release risk closeout이 먼저다.
- `9c3dd9e`, `6db92ea`, `da35e03` 이후 제품 기준과 운영 gate 분류가 바뀌었으므로 6차 문서 세트를 최신 기준으로 삼는다.

## 3. v1.0과 v1.1의 경계

- v1.0: 기존 기능을 안정화하고 현재 앱의 기능 기준선을 고정한다.
- v1.1: 과금, AI, private letters 확장, typography, 운영/admin 고도화 같은 신규 업데이트 후보를 다룬다.
- 운영자 QA, 실기기 최종 스모크, provider console/OAuth smoke, 스토어 자산, 최종 RC build evidence는 v1.1 착수 전 v1.0 마감 gate로 수행한다.

## 4. v1.0 기준선 요약

- Auth/email-password, social login app-side entrypoint, password reset, nickname/onboarding boot contract를 유지한다.
- Google/Kakao/Naver social login은 app-side 마감 상태다.
- Apple social login은 Android-first v1.0 범위에서 제외한다.
- social login 버튼 하단에는 이용약관/개인정보처리방침 확인 및 동의 간주 고지 UI를 추가했다.
- Supabase DB migration release gate는 closed다. remote apply는 no-op이고 pending migration은 없다.
- 커뮤니티, 건강관리, 동물병원, 날씨 비용 방어는 v1.0 기준선에 포함한다.

## 5. v1.1 업데이트 방향 요약

- Entitlement / billing foundation은 v1.1 신규 업데이트 후보로 관리한다.
- Premium AI reply는 notice, consent, generation log, provider policy를 선행조건으로 둔다.
- Guestbook private letters 확장은 기존 단순 방명록과 분리해 확장 기능으로 다룬다.
- Typography foundation rollout은 전면 리디자인이 아니라 제한 화면군부터 적용 여부를 판단한다.
- Apple social login은 iOS 출시 및 Apple 정책 검토 시점에 별도 판단한다.

## 6. v1.0 잔여 task/risk closeout gate

아래 항목들은 신규 기능 개발이 아니며, v1.1로 넘어가기 전에 v1.0 마감 lane에서 닫는 운영/제출 gate다.

- Google/Kakao/Naver provider console 설정 확인과 OAuth 성공 smoke
- 운영자 QA / 실기기 최종 스모크
- 앱 스토어 출시 자산 셋업
- 최종 제출용 RC 빌드 확정
- clean artifact evidence 고정
- release risk ledger 전수 정리와 남은 P0/P1/P2 재분류

## 7. 이전 1차~5차 기획서와의 관계

기존 1차~5차 기획서는 당시 의사결정과 제품 방향을 보존하는 기록이다. 최신 v1.0 기준선과 v1.1 업데이트 계획은 이 문서와 아래 두 문서를 기준으로 한다.
