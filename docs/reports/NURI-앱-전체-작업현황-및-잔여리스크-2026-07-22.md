## 최신 상태: 댓글 알림 딥링크 closeout

댓글 알림을 누르면 대상 게시글의 본문 시작이 아니라 해당 댓글 또는 답글 위치로 이동하도록 구현하고 Android 실기기에서 검증했다. 알림 action target은 서버 read model에서 UUID 형식과 허용 kind를 검증한 뒤 전달하며, 앱은 부모 thread를 자동 확장하고 target row를 강조한다. 유효하지 않은 target은 게시글 상세 fallback으로 처리한다.

## 2. 이번 closeout

- 커뮤니티 목록을 한 줄 제목, 중앙 정렬 유형 icon, 진한 divider, 우측 댓글 rail의 밀도형 게시판으로 정리했다.
- 기존 카테고리 `질문`, `팁 공유`, `일상`, `정보`와 cursor pagination을 유지했다.
- 타인 첫 조회 `+1`, 동일 사용자 6시간 window 재조회 `+0`을 controlled authenticated E2E로 확인했다.
- 타인 댓글이 `adminQA` Home unread badge와 알림함에 작성자 및 게시글 맥락으로 표시됨을 확인했다.
- 댓글 알림을 누르면 대상 게시글 상세로 이동하고, 부모 thread를 펼친 뒤 해당 댓글·답글을 viewport에 노출·강조한다.
- 댓글 알림은 인앱 row만 생성하고 actual push는 호출하지 않는다.
- 댓글 수 파생 집계 drift를 active 댓글·답글 source row 기준으로 교정하고 soft 상태 변경 trigger를 복구했다.
- QA 댓글은 soft-delete, 알림은 read 처리해 원상복구했다. hard delete는 0건이다.
