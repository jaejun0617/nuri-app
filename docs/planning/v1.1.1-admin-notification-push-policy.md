# V1.1.1 운영자 알림 발송 관리 체계 / Push 기반 정책

최신 갱신: 2026-07-11

## 판정

운영자 알림 발송 관리 체계는 앱 내부 일반 사용자 UI가 아니라, 별도 홈페이지/관리 페이지 트랙으로 운영한다. 2026-07-10 기준 별도 정적 관리 콘솔 `admin-console/notification-console.html`을 추가했고, 앱 내부 발송 화면은 열지 않는다.

## 구현 범위

- `admin_notification_campaigns`: 운영자 발송 기록.
- `admin_notification_audit_logs`: 운영자 발송 감사 로그.
- `admin_send_user_notification_v1`: admin/super_admin 전용 특정 사용자 앱 내부 알림 생성 RPC.
- `admin_send_qa_user_notification_v1`: 관리 콘솔 전용 admin-only QA 닉네임 wrapper RPC. 콘솔에는 raw user id를 노출하지 않는다.
- `admin_notification_audit_feed_v1`: 관리 콘솔 전용 제한 audit feed RPC. target label/title/type/status만 반환한다.
- `create_qa_user_notification_v1`: `adminQA`, `adminQA3~adminQA8` 닉네임 계정만 자기 자신에게 QA retention smoke 알림을 만들 수 있는 제한 RPC.
- `user_notifications.metadata`: 내부 감사/QA 용도의 선택 metadata. 앱 read RPC에는 반환하지 않는다.
- `admin-console/notification-console.html`: 별도 관리 페이지 UI. 발송 form, QA 대상 선택, preview, disabled broadcast, QA self smoke, audit log 상태를 제공한다.

## 보안 정책

- anon 호출 차단.
- non-admin의 운영자 발송 RPC 차단.
- `adminQA`에는 admin 권한을 부여하지 않는다.
- QA 알림 생성 RPC는 자기 계정에만 row를 생성한다.
- service role key, FCM key, Expo token 등 secret을 요구하거나 로그로 남기지 않는다.
- 앱 내부 일반 사용자 메뉴에 운영자 발송 UI를 노출하지 않는다.
- 전체 사용자 broadcast는 UI와 RPC wrapper 정책에서 비활성화한다.
- 관리 콘솔은 publishable key와 관리자 로그인 세션만 사용한다. service role key와 push secret을 입력하거나 저장하지 않는다.

## Push Notification 정책

이번 턴에서 remote push 발송은 구현하지 않는다.

다음 구현 트랙 source of truth는 `docs/planning/v1.1.1-push-token-opt-in-next-track.md`다.

후속 구현 선행 조건:

- push permission UX와 opt-in/opt-out 문구 확정.
- Android notification channel 설계.
- device token 저장/refresh/logout/delete 처리 정책.
- 발송 queue, retry, 실패 로그, quiet hours 정책.
- 운영자 발송 관리 페이지에서 push 대상/예약/취소/감사 로그 관리.
- FCM/Expo push secret은 서버/edge function secret store에서만 사용.

## Live Retention Smoke

2026-07-10 기준 새 알림 row 생성 안전 경로와 live retention visual smoke를 확보했다.

- 운영자 경로: admin-only `admin_send_user_notification_v1`.
- 관리 콘솔 경로: admin-only `admin_send_qa_user_notification_v1`.
- QA 경로: `adminQA` 계열 닉네임만 호출 가능한 `create_qa_user_notification_v1`.
- anon negative smoke: `admin_send_qa_user_notification_v1`, `admin_notification_audit_feed_v1` 모두 401/42501 blocked.
- non-admin smoke: `adminQA` 일반 사용자 JWT claim 모의 호출에서 admin send RPC 42501 차단.
- admin send smoke: 기존 admin profile claim으로 `adminQA` 단일 대상 알림을 생성했고 `admin_notification_campaigns`/audit feed에 기록됨을 확인했다.
- Android visual smoke: 홈 overlay 표시, home swipe dismiss, 알림함 유지, 알림함 개별 삭제, 전체삭제, 홈 재노출 없음 확인.
