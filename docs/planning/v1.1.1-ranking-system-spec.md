# V1.1.1 누리 랭킹 시스템 1차 MVP

최신 갱신: 2026-07-11

## 목표

전체메뉴에서 진입 가능한 `누리 랭킹` 화면을 제공한다. 랭킹은 경쟁을 과하게 자극하지 않고, 반려동물 활동을 차분하게 응원하는 성장형 아카이브 톤으로 표시한다.

## 구현 범위

- 위치: `전체메뉴 > 활동 및 기록 > 누리 랭킹`.
- 화면: `src/screens/Ranking/NuriRankingScreen.tsx`.
- 서비스: `src/services/ranking/activityRanking.ts`.
- 서버 RPC: `get_activity_ranking_v1`.
- 탭: 종합, 산책, 글, 댓글, 건강, 생활, 미용.
- 차트: 카드형 기둥그래프 리스트.
- 상태: loading, empty, error, refresh.

## 레벨 정책

Lv.1~30은 기존 사용자의 레벨 하락을 막기 위해 기존 threshold를 유지한다. 2026-07-11 pre-store polish에서 Lv.31~100을 추가했고, Lv.100 max threshold는 `1,250,000 XP`로 고정한다. Lv.31 이후는 후반으로 갈수록 요구 XP가 커지는 장기 curve이며, Lv.100 이상은 무한 레벨로 표시하지 않고 `최고 레벨 달성` 정책을 사용한다.

## Privacy / RLS

- 랭킹 RPC는 email, phone, user_id, pet_id, raw id를 반환하지 않는다.
- 일반 사용자 display는 `누리 친구 N`으로 마스킹한다.
- 현재 사용자만 `나`로 표시한다.
- QA fixture는 `adminQA` 계열 닉네임에서만 `p_include_qa_fixture=true` 요청 시 합산된다.
- pending deletion 계정은 랭킹에서 제외한다.
- anon 호출은 차단된다.

## QA Fixture

`activity_ranking_qa_fixtures`에 deterministic fixture 6개를 둔다.

| Fixture | 목적 |
| --- | --- |
| adminQA3 | Lv.100 / max XP / 종합 1위 |
| adminQA4 | 댓글 강세 |
| adminQA5 | 글·건강 강세 |
| adminQA6 | 생활 강세 |
| adminQA7 | 중간 활동 |
| adminQA8 | 낮은 활동 / 하위권 |

Fixture는 실제 사용자 auth 계정이 아니며, 일반 사용자 랭킹에는 섞이지 않는다.

## 남은 후속

- opt-in 기반 공개 닉네임 노출 정책.
- 차단/비공개 사용자 정책.
- 운영자 관리 페이지에서 fixture 포함 여부와 랭킹 상태 점검.
- 성능이 필요해지면 materialized summary 또는 scheduled aggregate로 분리.
