## Read Path 정책

1. 앱은 산책 도메인에서 자체 POI RPC를 먼저 호출한다.
2. 자체 POI 결과가 있으면 NURI canonical POI 결과를 우선 표시한다.
3. 자체 POI 결과가 없거나 RPC가 실패하면 기존 `location-discovery-seed` Edge Function 경로로 fallback한다.
4. Kakao Local은 이번 단계에서 삭제하지 않는다.
5. canonical POI는 provider thumbnail enrichment를 요청하지 않는다.

## 최소 Seed 정책

- seed는 대량 import가 아니라 Android smoke용 최소 approved row다.
- source provider는 `operator-seed`로 기록한다.
- import batch/source record/review/audit 이력을 남긴다.
- rollback은 `external_source_id` prefix `nuri-v1.1-smoke-` 기준으로 수행할 수 있다.
- 1차 서울시청 fallback seed는 실기기 현재 위치 radius 밖이라 public projection에서 제외하고, 최종 public seed는 일산3동/주엽동 현재 위치 주변 3건으로 고정한다.

- `confidenceScore`
- `qualityScore`
- `rawPayload`

Conflict key 후보:

- `source_provider + externalSourceId`
- normalized name + address
- coordinate proximity
- alias overlap

후속 commit/review 정책:

- dry-run은 실제 public 노출을 만들지 않는다.
- commit은 source record와 review 후보를 만든다.
- public read는 approved/public/active canonical row만 RPC로 반환한다.

## Admin Import Commit / Review Contract

RPC:

- `walk_poi_admin_import_commit_v1`
- `walk_poi_admin_review_v1`

정책:

1. `walk_poi_admin_import_commit_v1`은 admin/super_admin만 호출할 수 있다.
2. commit은 import batch, hidden/pending canonical candidate, source record, pending review row, audit log를 만든다.
3. duplicate는 `source_provider + externalSourceId` 기준으로 skip/count 처리한다.
4. `walk_poi_admin_review_v1`은 `approve`, `reject`, `held` action을 지원한다.
5. approve된 row만 `approved/public/active`로 public RPC에 노출한다.
6. rejected/held/pending row는 public RPC에서 반환하지 않는다.
7. 모든 action은 review/audit log에 남긴다.

상세 문서:

- `docs/domains/산책-위치기반-기능/v1.1-walk-poi-admin-import-review.md`
- `docs/domains/산책-위치기반-기능/v1.1-walk-poi-seed-strategy.md`

## Coverage / Fallback Gate

이번 단계에서는 Kakao Local fallback을 줄이지 않는다. 축소 gate만 정의한다.

Gate 기준:

- 우선 지역 approved/public/active POI count 충분
- nearby/search hit-rate 안정
- empty state 비율 안정
- public RPC error rate 안정
- rejected/held/pending public 누수 0건
- admin import rollback/held 기준 준비
- Android 실기기 리스트/검색/상세 smoke 통과

fallback 축소 전까지 앱은 POI RPC 우선 + 기존 `location-discovery-seed` fallback 병행 구조를 유지한다.
