## 범위

이번 V1.1 1순위 마일스톤은 산책/location discovery를 자체 POI DB + Supabase PostGIS 기반 read path로 전환하는 작업이다.

V1.0 기능은 재오픈하지 않는다. Play Store 제출 자산은 전체 개발/QA 종료 후 최종 제출 직전 준비로 유지한다.

## Read Path 정책

1. 앱은 산책 도메인에서 자체 POI RPC를 먼저 호출한다.
2. 자체 POI 결과가 있으면 NURI canonical POI 결과를 우선 표시한다.
3. 자체 POI 결과가 없거나 RPC가 실패하면 기존 `location-discovery-seed` Edge Function 경로로 fallback한다.
4. Kakao Local은 이번 단계에서 삭제하지 않는다.
5. canonical POI는 provider thumbnail enrichment를 요청하지 않는다.

## 최소 Seed 정책

- seed는 대량 import가 아니라 Android smoke용 최소 approved row다.
- source provider는 `operator-seed`로 기록한다.
- import batch/source record/review/audit 이력을 남긴다.
- rollback은 `external_source_id` prefix `nuri-v1.1-smoke-` 기준으로 수행할 수 있다.
- 1차 서울시청 fallback seed는 실기기 현재 위치 radius 밖이라 public projection에서 제외하고, 최종 public seed는 일산3동/주엽동 현재 위치 주변 3건으로 고정한다.

## Admin Import Dry-run Contract

필수 payload 필드:

- `externalSourceId`
- `name`
- `category`
- `categoryLabel`
- `address`
- `roadAddress`
- `latitude`
- `longitude`
- `aliases`
- `attribution`
- `confidenceScore`
- `qualityScore`
- `rawPayload`

Conflict key 후보:

- `source_provider + externalSourceId`
- normalized name + address
- coordinate proximity
- alias overlap

후속 commit/review 정책:

- dry-run은 실제 public 노출을 만들지 않는다.
- commit은 source record와 review 후보를 만든다.
- public read는 approved/public/active canonical row만 RPC로 반환한다.
