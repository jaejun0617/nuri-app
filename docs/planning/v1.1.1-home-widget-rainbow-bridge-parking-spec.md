# V1.1.1 홈 위젯 / 무지개다리 Parking Spec

최신 갱신: 2026-07-09

## 홈 위젯

이번 턴에서는 구현하지 않는다. 기존 release gate는 유지한다.

후속 설계 기준:

- Android AppWidget native 재설계 필요.
- 표시 후보: 오늘 산책, streak, 반려동물 이름, 날씨 요약.
- 개인정보 노출 위험: 홈/잠금 화면에서 타인이 볼 수 있는 surface이므로 opt-in과 민감 정보 제한 필요.
- 업데이트 주기: 배터리와 백그라운드 제한을 고려해 과도한 refresh 금지.
- QA: Android native 실기기, cold start, 재부팅, 앱 삭제/로그아웃 후 상태 검증 필요.
- release gate: 별도 native 트랙 전까지 release build 노출 금지.

## 무지개다리 서비스

이번 턴에서는 구현하지 않는다. 감정적으로 민감한 기능이므로 UX/문구/정책 선행이 필요하다.

원칙:

- 과장된 위로, 상품 구매 유도, 의료/장례 판단을 암시하는 문구 금지.
- 사용자가 먼저 선택하기 전까지 일반 기록 흐름에 노출하지 않는다.
- 프로필 상태값과 연결 가능하지만, 상품/문의/결제 flow는 후순위다.
- 문의 flow를 만들 경우 운영 응대 SLA, 개인정보 처리, 삭제/복구 정책이 먼저 필요하다.

추천 문구 방향:

- “함께한 시간을 조심스럽게 보관해요.”
- “아이의 기록을 더 편안한 방식으로 정리할 수 있어요.”

금지 문구 방향:

- “상실을 극복하세요.”
- “지금 구매하세요.”
- “장례/의료 결정을 대신 안내합니다.”

## Kakao Local Global Hard Delete

이번 턴에서도 Parking 유지한다.

- Walk/Hospital runtime 의존이 완전히 사라졌다고 단정하지 않는다.
- coord2region, 후보 matching, 기존 place enrichment 경로를 다시 확인하기 전까지 provider/global config 삭제 금지.
- 비용/호출 제한은 후속 audit에서 확인한다.
