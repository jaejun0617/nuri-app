# 다음 작업 우선순위

이 문서는 **현재 승인 범위와 유일한 실행 대기열**을 소유한다. 2026-11-11 운영지침 개편 PO 지시 기준이다. [현재 상태](현재-프로젝트-상태.md#current-baseline)의 제품·수락과 [단일 원장](../qa/nuri-integrated-closeout-2026-10-25.md)을 재사용한다. 문서에 작업이 있다는 사실은 새 실행 승인이 아니다.

<a id="resume-point"></a>
## 정확한 다음 실행 지점

**다음 실기기 재개점은 월별 지출→전체메뉴→다음 메뉴 입력이다.** [이번 U1·NAV 증분](../qa/nuri-c0-app-linkage-2026-11-11.md#2026-11-13-u1-google-취소와-nav-01-실기기-검증)의 수정 APK를 만들기 전 가용 25 GiB를 다시 확인한다. Google 동의·재인증은 정상 제공자 화면을 확보할 수 있을 때만 재개한다. U2 개인 A·B와 공지 검증은 재사용하고 두 보류·C0 미동결·STORE HOLD를 유지한다.

기존 `news.direct`·공지 7종·`pet.together_anniversary`·`pet.memorial`의 격리 앱 증거와 전체 삭제 확인·확정 PASS는 영향이 없으면 재사용한다. 네트워크 실패 복구와 정상 삭제 성공을 다른 조건으로 다룬다. 기존 Google/Kakao 보존 알림함은 전체 삭제하지 않는다. 제품·server·runtime 입력 불변이면 재빌드하지 않는다.

한 번 승인된 후속 U2→U1→NAV→C0 연속 범위에서는 단건마다 재승인을 요청하지 않는다. 이번 문서 작업의 종료 경계를 과거 연속 승인으로 넘어가지 않으며 [계속/중단](../engineering/advanced-codex-workflow.md#continue-stop)을 따른다.

## 미승인 후속 제안

신규 5종 기획은 리서치의 기존 통합 구현순서 제안 상태이며 제품 구현은 시작하지 않았다. 원래 번호는 7 산책 장애, 8 산책 정확도, 9 전체 화면 회귀, 10 최종 보안, 11 정책·법무, 12 최종 RC, 13 Store 자료, 14 베타·Store 각각 PO Go/No-Go로 유지한다. 현재 제품 잔여·승인 범위 확정·각 선행 조건 이후에만 배치한다. 이 표 밖의 새 작업이나 문서 정리 차수를 자동 생성하지 않는다.

## 재사용할 완료 근거

- [연 기념일·추모 2/2](../qa/nuri-c0-app-linkage-2026-11-11.md#2026-11-11-u2-연-기념일과-추모-격리-설치본-e2e), [공지 7/7](../qa/nuri-c0-app-linkage-2026-11-11.md#2026-11-11-u2-공지-7종-격리-설치본-e2e)와 그 절이 연결한 기존 news.direct는 격리 환경 증거다. 운영 Cron·OS push로 승격하지 않는다.
- [C0 앱 연결 보고](../qa/nuri-c0-app-linkage-2026-11-11.md)의 정상 전체 삭제·삼성 인터넷·Chrome·가이드 Back, [연속 검증](../qa/nuri-c0-continuous-verification-2026-11-11.md)의 명시 Home·일정 Back·취소를 해당 후보/조건에서 재사용한다.
- 원장의 OS 13/13·기록 4/4 내부 동결과 U2 최초 읽음·경합·정상 원본별 PASS를 보존한다. 새 영향이 없으면 전수 반복하지 않는다.
- MD·SQL 정리 1~12차는 마감된 상태다. 8차 뒤 원문 번들 정리·SQL 필요성 판단은 이미 후속 차수에서 처리됐으므로 현재 큐에 남기지 않는다.

## 과거 요구의 적용성 판단

새 필수 분모나 자동 실행 목록이 아니다. QA-PHOTO 부재 원인·시점, 과거 QA 일정/댓글/사진 ID별 정리, Google 브랜드 노출/게시, Log Ingestion 이후 관측, 과거 SEC-011과 후속 보안 동결의 세부 적용성은 이번에 재감사하지 않았다. 각각 기존 영수증·소유 ID·해당 도메인 후속 근거가 필요하다. 임의 재생성·전체 삭제·운영 조회·보안 PASS 승격을 하지 않는다.

구체 원문은 [개편 전 고정 우선순위](https://github.com/jaejun0617/nuri-app/blob/4d03428c29a3d84ea71ee5fa1396f1b92a42712e/docs/project-memory/다음-작업-우선순위.md#과거-요구의-적용성-판단)에 남긴다. [상태·우선순위 통합 이력](아카이브/상태-우선순위-통합이력-2026-11-09.md)은 당시 승인·실패·후속의 보존 위치이지 두 번째 현행 대기열이 아니다.

## 개편과 전달 근거

이전 HEAD의 큐·승인·원래 7~14는 위 고정 원문으로, 기존 미전달 고유 증분은 로컬 보존 구간과 수정 직전 원본으로 추적한다. [개편 로그](최근-작업-로그.md#2026-11-11-codex-운영지침-개편)에 원문 대응·평가·commit/CI 영수증을 연결한다. 이번 신규 제품 QA·수락 원장 변경은 없고 통합 4/7·C0 미동결·STORE HOLD를 유지한다.
