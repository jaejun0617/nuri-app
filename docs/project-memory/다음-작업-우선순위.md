### 1. place enrichment background cron worker

- 이유
  - `pg_cron -> Edge Function worker -> shared provider adapter -> budget gate` 구조 자체는 닫혔다.
  - Task 9/10 고도화로 provider cache가 opening hours/website/dynamic status TTL까지 확장됐다.
  - 이제 남은 것은 old provider cache row 중 photo 없는 row, hours stale row, walk observed cache의 refresh 우선순위를 더 정교하게 다듬는 일이다.
- 선행 조건
  - Google quota alert와 budget hard cap 운영값 재확인
  - stale cache refresh 우선순위 정의
  - 동물병원 상세 hours 호출량 24시간 모니터링
  - 산책 `location-discovery-seed` 호출량 24시간 모니터링

- 선행 조건

  - 검수 UI approve/reject/held 조작 증적
  - pending thumbnail/coordinates/open24 queue 운영 기준 재정리

## 왜 이 순서인가

- 지금은 출시가 아니라 구현 완성도가 먼저다.
- release lane은 삭제하지 않되, 모든 핵심 task가 닫힌 뒤 마지막 게이트로 미룬다.
- 먼저 해야 하는 것은 제품 구조를 실제 방향인 `병원 / private letters / entitlement / social auth / Premium AI 선행조건`으로 옮기는 일이다.
