## 이미 완료되어 다시 시작하지 않는 조건

- **U2 신규 유입·읽음 경합:** 최초 읽음 보존, 단건과 모두 읽음 경합, 서버 대상 밖 신규 알림의 미읽음 유지 및 앱 최종 집계는 [최신 U2 수락](../qa/nuri-integrated-closeout-2026-10-25.md#2026-11-09-u2-모두-읽음-중-신규-알림-유입-및-전달)을 재사용한다. 반대 서버 순서나 공지를 새 필수 시험으로 추가하지 않는다.
- **OS·생일:** OS05·OS10·OS13 및 11/07 정상 생일 원본의 OS 후속은 [B단계 수락](../qa/nuri-integrated-closeout-2026-10-25.md#2026-11-07-b단계-생일-정상-원본과-os05-수락)과 후속 내부 동결을 따른다. 생일 캡처 대기·OS10 동일 프로브·24시간 도달 대기를 다시 만들지 않는다.
- **기록:** 사진 참조·큐·계정 교차, 일반 기록 초안, 건강 최신값·응답 복구, 일정 취소·예약 경합은 [U5 마감](../qa/nuri-integrated-closeout-2026-10-25.md#2026-11-09-u5-건강일정-실기기-마감과-사진-편집-경합)을 따른다. Google attempts5의 11:51 완료를 이전 11:46 관찰로 되돌리지 않는다.
- **목적지·복귀:** 일정 실제 알림 진입·성공 후 읽음·Back, 접근 불가 수정 알림 미읽음과 기존 삭제 공지 읽음, 댓글 연속 탭의 한정 PASS를 반복하지 않는다. NAV 전체 수락으로 확대하지 않는다.
- **디자인·전달:** 과거 Metro 검토·최종승인·설치 대기는 해당 날짜의 이력이다. 현재 승인 디자인과 고정 CTA·글자 크기를 유지하고 새로운 디자인 작업을 시작하지 않는다.

## 정확한 다음 실행 지점

이번 로그 전달을 마친 뒤에는 **리서치의 남은 미전달 구간 대조를 다음 문서 후보로 제시하고 PO의 별도 지시를 기다린다**. 전체 MD 전수 조사나 SQL 실행 구조 변경은 시작하지 않는다. 문서·SQL 정리 후 PO가 기능 재개를 승인하면 U2의 미수락 업무 원본 한 개를 먼저 선정한다. 그때 원장의 17묶음·26종과 유효 증거를 대조하고 이미 수락한 경합·생일·일정 경로를 제외한 원본→목적지→읽음 공백을 확인한다. U2→U1→NAV 순서는 유지한다.
