### 1. 우리동네 동물병원 foundation

- 이유
  - 도메인 foundation은 repo와 remote schema 기준 상당 부분 올라왔고, 운영 검수 결과가 public projection에 반영되는 Android 실기기 증적도 확보됐다.
  - 현재 코드 기준 운영자 검수 UI, summary RPC, thumbnail import dry-run, delta/drift/provider summary, linked SQL seed, approved CTA smoke까지 생겼다.
  - 앱 쪽 P0-P2 후속인 전국 검색, 위치 문구 보정, 전화번호 하이픈 표시, 최근검색어 제거, 가까운순/verified 24시 운영 칩, Android CTA smoke는 닫혔다.
  - 2026-04-23 repo 기준 provider enrichment pipeline, `open24Hours` admin 검수 확장, 위치 정확도 P0 보강, Google/fixture/Kakao dry-run, Android 리스트/상세/전화/지도 재캡처까지 완료됐다.
  - 남은 blocker는 `20260423090000` remote migration 적용, service role 기반 운영 스크립트 apply mode 재실행, 실제 admin 계정에서 검수 UI approve/reject/held 조작을 시각 검증하는 일이다.
- 선행 조건
  - `SUPABASE_ACCESS_TOKEN`으로 local migration remote 적용
  - `SUPABASE_SERVICE_ROLE_KEY` 또는 정상 linked DB query 권한
  - `GOOGLE_PLACES_API_KEY` 또는 현재 provider key가 있는 운영 환경에서 대량 enrichment 재실행
  - `KAKAO_REST_API_KEY`가 있는 운영 환경에서 runtime provider snapshot 재실행
  - script apply mode로 official thumbnail manifest 재실행
  - admin 계정으로 운영자 화면 직접 진입
  - 검수 UI approve/reject/held 조작 증적
  - 운영시간 문자열 전체를 public에 열려면 별도 source schema와 approved verification policy 확정
