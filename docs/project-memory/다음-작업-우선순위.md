# 다음 작업 우선순위

## 운영 원칙

- v1.0은 기존 기능을 안정화해서 출시한다.
- 이번 Auth 마감 이후 v1.0 기능 개발은 Code Freeze로 간다.
- v1.1은 v1.0 미완성 이월이 아니라 신규 업데이트 트랙이다.
- v1.0 gate가 닫히기 전에는 v1.1 기능 개발에 착수하지 않는다.
- 날씨와 동물병원처럼 이미 PO lock-in 된 도메인은 v1.0 blocker가 새로 확인되지 않는 한 다시 열지 않는다.

## v1.0 Code Freeze 이후 남은 작업

### 1. Supabase DB Migration Dry-run / 원격 Apply

- pending migration 목록을 dry-run으로 먼저 확인한다.
- 이번 배포에서 승인된 migration만 remote apply 대상에 포함한다.
- 의도하지 않은 pending migration이 있으면 remote apply를 중단한다.
- remote apply 후 migration list, lint, 필요한 RPC evidence를 남긴다.

### 2. 운영자 QA / 실기기 최종 스모크

- 운영자 QA final gate는 v1.0 제출 전 수행하거나 PO가 명시적으로 보류 승인한다.
- Android 최종 smoke는 Code Freeze 커밋 이후 PO 최종 QA 항목으로 유지한다.
- Google/Kakao/Naver provider console 설정과 OAuth smoke는 기능 개발이 아니라 최종 운영 확인 항목으로 둔다.
- social login 앱 코드는 v1.0 app-side 마감 상태로 고정한다.

### 3. 앱 스토어 출시 자산 셋업

- Play Store 스크린샷을 준비한다.
- 스토어 설명문, 문의처, 정책 URL을 최종 점검한다.
- 실제 제출 빌드 버전 메타데이터와 스토어 자산을 일치시킨다.

### 4. RC 빌드 확정

- 최종 release candidate build artifact를 확정한다.
- package name, versionName, versionCode, signing config를 제출 빌드 기준으로 확인한다.
- 제출 직전 빌드 provenance를 기록한다.

### 5. Clean artifact evidence 고정

- clean working tree 또는 명시 승인된 release branch 기준으로 evidence를 고정한다.
- 2026-04-30 RC smoke가 dirty working tree 기준이었음을 유지하고, 최종 제출 전 clean artifact evidence로 닫는다.
- 이 항목은 현재 v1.0 release evidence blocker다.

## v1.0 Auth / Social Login Scope

- Google/Kakao/Naver social login은 v1.0에서 app-side 마감 상태로 고정한다.
- Google/Kakao는 Supabase built-in provider, Naver는 Supabase custom OAuth provider id `custom:naver`를 사용한다.
- provider console 설정과 OAuth success smoke는 release checklist의 최종 운영 확인 항목으로 남긴다.
- social login 버튼 하단에는 이용약관/개인정보처리방침 확인 및 동의 간주 고지 UI를 둔다.
- v1.0에서는 별도 social consent DB snapshot, 신규 migration, 신규 RPC를 열지 않는다.
- Apple social login은 v1.0 제외다.

## v1.0에서 열지 않는 것

- 실제 결제/과금 구조를 열지 않는다.
- Premium AI reply를 열지 않는다.
- Guestbook private letters 확장 아키텍처를 열지 않는다.
- Guestbook은 기존 단순 방명록 상태로 출시한다.
- Typography foundation rollout을 진행하지 않는다.

## 왜 이 순서인가

- v1.0은 더 이상 신규 기능을 늘리지 않고 운영/QA/스토어/RC evidence로 마감한다.
- 현재 사용자 화면에 노출되는 Google/Kakao/Naver social login은 app-side 마감 상태로 고정하고, 남은 것은 provider 설정과 smoke다.
- 과금, Premium AI, private letters 확장, typography rollout은 v1.0 완성도를 흔드는 신규 기능이므로 v1.1 업데이트 후보로 분리한다.
- clean RC artifact와 스토어 제출 자산은 최종 출시 직전의 필수 게이트다.
