## 보류와 승인 경계

- `record.monthly_summary`: PO 보류. 2026-12-01 09:00 KST 이후 적격 11월 정상 원본·PO 기기 증거가 재개 조건이다. 과거 BLOCKED 이력을 보존하며 예약·상시 감시·read_at 초기화를 만들지 않는다.
- `pet.together_month`: PO 재개와 실제 적격 원본까지 보류. `pet.together_anniversary` 및 `news.monthly_editorial`과 다르다.
- 신규 기획 5종은 **IMPLEMENTATION_SEQUENCE_PROPOSAL / PENDING_PO_SCOPE_APPROVAL / NEW_FEATURE_IMPLEMENTATION_NOT_STARTED**다. 제안이 실행 권한이 되지 않는다.
- 이번에는 운영지침 개편만 승인됐다. 제품·SQL·기기·운영 데이터·수락 원장 변경 0을 유지하며 U2·U1·NAV를 자동 재개하지 않는다. 원래 7~14·출시는 별도다.

## 문서와 보존 범위

MD·SQL 정리 1~12차의 마감·SQL 231개 유지 판단은 재사용한다. 새 전체 MD·SQL 감사를 시작하지 않는다. [역할 안내](../README.md), [SQL 소비 관계](../sql/정리-가이드.md), [핵심 결정](핵심-결정사항.md#decision-scope-map), [최근 로그](최근-작업-로그.md), [통합 이력](아카이브/상태-우선순위-통합이력-2026-11-09.md)이 각 근거를 소유한다.

이 문서 개편 전의 11/09 기준표·과거 8차 안내는 [시작 HEAD 고정 원문](https://github.com/jaejun0617/nuri-app/blob/4d03428c29a3d84ea71ee5fa1396f1b92a42712e/docs/project-memory/현재-프로젝트-상태.md)에 보존되어 있다. 과거 caad80a·APK·계정 선택은 현재값이 아니다. 미전달 로컬 고유 기록은 working tree의 로컬 보존 구간과 수정 직전 보존본으로 유지하고 이번 원격 전달에서는 제외한다.

수락 원장·QA 앱 연결 보고·리서치의 기존 dirty, 미추적 보고서·이미지·CLI metadata·저장소 밖 영수증은 보존 대상이다. 외부 파일의 존재·내용 재검증·현재 운영 적용성은 같은 상태가 아니며, 이번에 재검증하지 않았다. [과거 요구의 미확정 범위](다음-작업-우선순위.md#과거-요구의-적용성-판단)를 새 blocker로 올리지 않는다.

개편의 원본·복원·대응·정적 평가·모의 판단·전달 영수증은 [이번 로그](최근-작업-로그.md#2026-11-11-codex-운영지침-개편)에서 연결한다. 문서 내용 검토와 다음 실제 작업에서의 지침 적용 확인은 별도다.
