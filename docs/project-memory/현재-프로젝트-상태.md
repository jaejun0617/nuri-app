# 현재 프로젝트 상태

## 2026-11-09 현재 기준 요약

이 문서는 현재 제품·수락·잔여의 요약이다. 실제 판정과 검증 한계는 [단일 수락 원장](../qa/nuri-integrated-closeout-2026-10-25.md)이 소유하고, 다음 실행은 [우선순위](다음-작업-우선순위.md)가 소유한다. 기준은 원장의 **2026-11-09 U2 모두 읽음 중 신규 알림 유입 및 전달**과 문서 정리 2차 시작 시점이다. 이번에는 앱·운영 DB·기기를 재조회하지 않았다.

**통합 4/7, 전체 미동결, STORE HOLD.** B1·B2·U3·U5가 수락됐고, U3 OS 13/13과 U5 기록 4/4는 내부 QA 동결이다. 문서 정리로 수락이나 출시 판단을 변경하지 않는다.

## 미완료 범위

- **U2 업무 원본:** 기존 17묶음·26종 중 한정 증거만 있는 생성·목적지·읽음 연결 공백. 전체 분자는 확정되지 않았으므로 임의 완료율을 만들지 않는다.
- **U2 운영:** 격리 QA 알림함의 전체 삭제 확정 실기기 E2E. 전체 삭제 취소·SQL 계약과 개별 삭제는 재사용한다. 기존 사용자 알림 전체를 지워 시험하지 않는다.
- **U1:** Google 계정 선택·동의·재인증·fallback 등 원장의 미수락 경로. 정상 인증·복귀 및 OS10 한정 PASS를 반복하거나 U1 전체 수락으로 확대하지 않는다.
- **NAV-01:** 기존 PASS 밖의 공통 이동·복귀와 원장의 시각적 전환 잔여. 최근 미재현만으로 과거 원인 해결을 선언하지 않는다.
- **통합:** U1·U2·NAV와 기존 필수 조건을 충족한 뒤 별도 동결 판단. 원래 7~14 및 출시 승인은 아직 열지 않는다.

## 유지할 제품 계약

- 서버·앱·실제 QA를 구분하고, QA 발송 제한·개인정보·XP·칭호 귀속을 보존한다. 현재 공개 인증 범위는 Google·Kakao이며 공개 이메일 가입·Naver는 제거, Apple은 OFF다.
- 일반 라벤더 CTA와 활동칭호 기준 글자 크기는 고정 정책을 따른다. [고정 디자인](핵심-결정사항.md#2026-11-06-po-고정-모든-후속-디자인의-cta와-글자-크기)의 사용자 글꼴·접근성·의미색 및 글등록/X 예외를 보존한다. 과거 아이스블루 배경 수치를 최신 정책으로 다시 적용하지 않는다.
- Candidate / Trust / User Layer를 분리하고 confirmed 개방을 추정하지 않는다. 공개 기능·moderation·개인화 경계는 [작업 규칙](../engineering/advanced-codex-workflow.md)과 [핵심 결정](핵심-결정사항.md)을 따른다.
- 과거 운영·릴리즈 gate와 v1.1 후보는 [10/29 이전 상태 이력](아카이브/현재-상태-정리전-2026-10-29.md)에 보존한다. 그 시점의 Code Freeze나 운영 PASS는 현재 전체 동결을 뜻하지 않는다. 현재 적용 여부가 미확정인 조건은 삭제·완료 처리하지 않는다.
