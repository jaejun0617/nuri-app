## 현재 목표

NURI의 현재 목표는 `v1.0 closeout 상태 유지 + v1.1 산책 POI PostGIS 기반 산책/location discovery 운영 확장`이다.

현재 판단 기준은 아래 3개다.

- V1.0 P0/P1 0건과 기능 Code Freeze 상태가 문서와 실제 evidence에 일치하는가

### 지도/API 비용 방어 Phase 1~2 후속

- v1.1 기준 후속이다.
- V1.0 Phase 0은 provider runtime 차단으로 마감한다.
- Phase 1은 운영자 batch/import 기반 approved 데이터 승격과 provider key 격리다.
- Phase 2는 MapLibre/PMTiles/자체 POI/PostGIS 기반 지도/장소 구조 고도화다.
- stale cache refresh 우선순위 조정과 walk domain의 비-observed 전국 seed source는 V1.1 후속으로만 다룬다.
- `open24Hours`, `exoticAnimalCare` 승인 정책은 cron에서도 그대로 유지해야 한다.
