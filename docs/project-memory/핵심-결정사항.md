- controlled Google QA identity로 신규 `PetCreate` 또는 테스트 반려동물 profile을 검증할 때 생일 입력값은 `2016-10-21`로 고정한다.
- `2016-10-21`은 QA fixture 입력 규칙일 뿐 일반 사용자 제품 기본값이나 자동 입력값으로 구현하지 않는다.
- OAuth QA 종료 시 provider email, access/refresh token, session payload는 문서·로그·Git 증적에 남기지 않는다.
