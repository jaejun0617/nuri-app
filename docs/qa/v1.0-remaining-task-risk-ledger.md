# V1.0 Remaining Task/Risk Ledger

작성일: 2026-05-08

## 1. 목적

이 문서는 v1.1로 넘어가기 전에 닫아야 하는 v1.0 잔여 task와 release risk를 단일 source로 고정한다. 기능 개발 Code Freeze는 유지하며, 아래 항목은 신규 기능 구현이 아니라 운영/검증/제출 안정성 closeout이다.

## 2. 무한루프 방지 원칙

- 이미 close된 동물병원, 날씨, 건강관리, 커뮤니티 기본 방어선, Supabase migration gate는 새 blocker 증거가 없으면 재오픈하지 않는다.
- RC smoke는 clean RC artifact가 준비되기 전까지 반복 실행하지 않는다.
- OAuth는 app-side 구현을 다시 열지 않고 provider console/Supabase 설정과 Android 성공 smoke만 본다.
- v1.1 후보를 v1.0 미완성 task로 끌어올리지 않는다.
- 같은 evidence gap을 여러 문서에서 따로 재분류하지 않고 이 ledger와 `docs/qa/release-checklist.md`만 갱신한다.
